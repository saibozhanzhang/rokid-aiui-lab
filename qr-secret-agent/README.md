# 扫一扫

普通人看到的是二维码，佩戴 Rokid Glasses 的人打开这个 AIUI Agent 后能看到被整理过的智能卡片。

## v1.0.38 能力

- 图片结果新增 SVG 兜底：遇到 `.svg` 图片链接会自动转成白底 PNG 再显示，适配眼镜端 `<image>` 的限制
- 图片页使用显式 `showImageView` 状态控制，减少真机模板表达式导致的误判
- 日程时间改成中文可读格式，例如 `2026年5月20日 19:30 - 21:30`

## v1.0.37 能力

- 修复 `LQ1:` 乐奇密文里的结构化内容分流：Wi-Fi、名片、目的地、日程不再显示成空白的“乐奇密文”卡
- 图片密文会直接进入图片显示模式，不再被当成普通链接卡片
- 继续保持“手机扫码看到密文，乐奇 AI 眼镜扫码看到漂亮卡片”的玩法

## v1.0.36 能力

- 新增 `LQ1:` 乐奇密文二维码：普通手机扫码只看到密文，扫一扫会本地解码成眼镜卡片
- 支持 `GLASS-LINK:{...}` 链接卡片，优先显示网站名称 / 功能，下一行显示网址
- 密文解码失败时显示友好提示，不暴露工程诊断信息

## v1.0.35 能力

- A2UI 生成 GUI 去掉深色卡片背景和内容区半透明底，只保留绿色线框与文字
- native 启动页、解码页、纯文本页、未识别页、密语页、音频页统一改为透明背景
- 小标签从绿色实心底改成透明描边，减少单绿色显示下的脏块感
- `app.json` 窗口背景也改为 `transparent`，避免页面容器兜底色露出

## v1.0.34 能力

- 音效本体从原始文件重新生成，增益下调约 `18dB`，比上一版明显更安静

## 服务

```text
Rokid BarcodeDetector
```

默认不依赖腾讯云，也不依赖本地电脑。

如果唤起参数里传入 `provider=cloud` 和 `endpoint`，才会使用外部兼容接口。
