现在推荐用 Craft 做

Craft 是 AIUI 的在线工作台。小白不用先被命令行吓住，先把项目导进去，看得见、改得动、跑得起来。

1. 导入项目

点左侧资源管理器里的导入按钮，选择本地文件夹，或者填 GitHub 子目录。

  • 本地文件夹：适合自己电脑里的项目
  • GitHub 子目录：适合照着官方 Sample 改
  • 导入后，左边会出现项目文件树

2. 在线编辑

在 Craft 里直接改 app.json、app.js、pages/index/index.ink。

  • app.json 管名字、版本、权限和页面
  • index.ink 管眼镜上看到的界面
  • 先改小地方，保存后立刻跑

3. 运行智能体

点右侧“运行智能体”，选择页面和参数。Craft 会创建 InkView 预览窗口。

  • 先看有没有显示
  • 再看按钮和状态有没有变
  • 真机能力还要上眼镜测试

4. 打包去发布

确认能跑以后，在 Craft 里生成 AIX，再去灵珠平台创建 AIUI 智能体。

  • 上传 AIX 软件包
  • 填写功能介绍和权限
  • 提交审核或安装到眼镜测试

一句话记住：Craft 负责“做和打包”，灵珠负责“提交和发布”。

灵珠平台怎么填？

Craft 生成 AIX 后，就到灵珠平台创建 AIUI 智能体。照这个填，小白也不慌。

基础信息

  • 类型：做完整界面选“场景智能体”
  • 名称：短一点，比如“扫一扫”
  • 版本：每次更新都加一位，比如 1.0.1
  • 类别：看用途选生活、工作、娱乐、学习

功能介绍

别写长作文。告诉用户：它是什么，能干嘛，什么时候用。

  • 例：戴上眼镜，扫一扫二维码，就能看到文字、网址和眼镜密语。
  • 例：适合聚会破冰、展会互动、朋友之间分享小秘密。

权限依赖

只勾真的用到的。勾太多，用户会紧张，审核也更麻烦。

  • 扫码、拍照：勾摄像头
  • 访问接口：勾网络
  • 没用语音，就别勾麦克风和语音识别

程序包和测试词

  • 上传刚打包出来的 .aix 文件
  • md5 通常平台会自动算
  • 测试词写自然一点：打开扫一扫，帮我识别这个二维码

小提醒：如果你上传后发现眼镜还是旧版本，先检查版本号、AIX 文件名、包内 app.json，很多“没更新”其实是装了旧包。

这 4 个坑，先躲开

都是眼镜上真实遇到过的问题。先知道，就少折腾。

交互

镜腿不是鼠标

眼镜腿单击像按 Enter，双击像按 Backspace。

退出

别一下子退出

双击先问“确定吗？”，再双击才退出。这样不容易误关。

界面

少写花活

页面代码越简单越稳。先别写太复杂的判断和样式。

能力

先做稳的

相机、图片、上网比较好用。声音、视频、语音要先真机试。

装上眼镜前，检查一下

先别急着加新功能。把这 4 件事做好，就很稳。

能看见

打开后有标题，有内容，字够大，不被挡住。

能点动

单击后有反应。不要点一下变成点很多下。

能说清失败

如果网络坏了，要告诉用户“没连上，请重试”。

能退出

双击先确认，再双击退出。别把人关在页面里。
