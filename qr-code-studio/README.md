# 扫一扫二维码创作台

给 Rokid Glasses / 乐奇 AI 眼镜「扫一扫」智能体准备二维码内容的本地网页。

## 用法

直接打开：

```text
index.html
```

网页会在浏览器里本地生成二维码，不需要后端服务。

## 支持的内容

- 所有类型：手机扫码只会看到一句提示语，乐奇 AI 眼镜会读出隐藏卡片
- Wi-Fi：眼镜端解码成 Wi-Fi 卡片
- 乐奇密文 / 文字卡片：适合在眼镜里显示一段清爽文字
- 图片：眼镜端直接显示图片
- 网址：眼镜端显示网站名称 / 功能，下一行显示网址
- 名片、电话、邮箱、目的地、日程：眼镜端解码成对应 GUI 卡片

## 眼镜友好原则

- 内容越短越好，二维码越稀疏，眼镜越容易扫到
- 图片请使用稳定的 HTTPS 直链
- 视频和音频在当前实测体验里不稳定，本工具先不主推
- 生成后优先下载 PNG，打印或展示时保持纯白底、高对比、正方形
- 如果浏览器没有自动下载，页面会显示保存面板，可以右键或长按预览图保存
