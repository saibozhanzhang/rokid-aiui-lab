# 扫一扫二维码创作台

给 Rokid Glasses / 乐奇 AI 眼镜「扫一扫」智能体准备二维码内容的本地网页。

## 用法

直接打开：

```text
index.html
```

网页会在浏览器里本地生成二维码，不需要后端服务。

## 支持的内容

- 像素密语：生成 `GLASS-SECRET:{...}`，适合在眼镜里显示像素风小图案或短句
- Wi-Fi：生成标准 `WIFI:T:...;S:...;P:...;;`
- 图片：生成 `IMAGE:https://...`，适合在眼镜里直接显示一张图
- 网址：直接生成 URL，眼镜端会显示链接卡片
- 名片：生成 `VCARD`
- 电话、短信、邮箱、位置、日程：生成扫一扫当前体验较好的结构化格式

## 眼镜友好原则

- 内容越短越好，二维码越稀疏，眼镜越容易扫到
- 图片请使用稳定的 HTTPS 直链
- 视频和音频在当前实测体验里不稳定，本工具先不主推
- 生成后优先下载 PNG，打印或展示时保持纯白底、高对比、正方形
