## 二、关键结论（可直接指导后续开发）

1. 现在最稳的路线是：**不依赖手机 UI，不依赖蓝牙外设，不依赖语音播报**。
2. 可以依赖的能力：**相机 + 网络 + HUD 文本显示 + 镜腿退出手势**。
3. TTS 在你当前真机环境中不稳定或不可听，短期内应采用“纯视觉反馈”。
4. 退出机制建议统一为：
- 首选 `wx.exitMiniProgram`
- 500ms 后 `wx.navigateBack({ delta: 1 })` 兜底
- UI 文案明确提示“连续双击两次退出”
5. Agent 设计策略应改为“零交互自动流程”优先：
- 打开即执行（自动拍照 / 自动上传 / 自动结果展示）
- 操作输入作为增强（单击重试、双击退出）
